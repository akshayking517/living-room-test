# Home box

A one-page check: can a quiet box about the size of a Wi-Fi router answer the devices in a house?

The box is not a router. Inside is a compute-in-memory chip that holds 80 million weights and uses about 4 watts. Slide the weights up. Past 80 million, the extra weights leave the chip.

Open `index.html` in a browser. No install. The same page is the GitHub Pages site.

- **Von Neumann / GPU** — every weight is hauled on every answer. 1.5 watts per 100 million, plus 3 watts for the box. One billion weights is 18 watts.
- **Compute-in-memory** — every weight stays in place. 0.15 watts per 100 million, plus 3 watts. Eight billion weights is 15 watts, still quiet.
- **Run 1,000 days of use** — another stretch of ordinary days
